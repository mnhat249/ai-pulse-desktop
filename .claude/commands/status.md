---
description: Tóm tắt trạng thái repo và worktree
allowed-tools: Bash(git status:*), Bash(git log:*), Bash(git worktree list), Bash(git diff:*)
---
Chạy `git status -sb`, `git worktree list`, `git log --oneline -5`. Tóm tắt ngắn: nhánh hiện tại, file đang thay đổi, worktree đang có, commit gần nhất.
